# Yahoo Finance Screener API Raw Sample - TOR

**Note:** The curl commands below now include 6-hour crumb caching. For production use, you can also use `fetch-screener-samples.js` or `fetch-raw-screener-samples.js`.

## API Parameters Used
- **Exchange**: TOR
  - Other possible values: TOR (TSX), CNQ (TSXV), NYQ (NYSE), NMS (NASDAQ), ASE (AMEX), PCX (Pacific Exchange)
- **Size**: 100
  - Other possible values: Any positive integer up to ~1000 (API limit varies)

## CURL Command to Replicate This Exact Response

```bash
# Step 1: Get session cookies
curl -c cookies.txt -s "https://fc.yahoo.com" > /dev/null

# Step 2: Get crumb token (with 6-hour caching)
if [ -f "yahoo-crumb-cache.json" ]; then
  # Check if cache file is less than 6 hours old
  if [ $(find yahoo-crumb-cache.json -mmin -360 2>/dev/null | wc -l) -eq 1 ]; then
    CRUMB=$(grep '"crumb"' yahoo-crumb-cache.json | sed 's/.*"crumb": *"\([^"]*\)".*/\1/')
    echo "Using cached crumb (file modified < 6 hours ago)"
  else
    echo "Cached crumb expired, refreshing..."
    CRUMB=$(curl -s -b cookies.txt "https://query1.finance.yahoo.com/v1/test/getcrumb")
    echo "{\"crumb\":\"$CRUMB\",\"timestamp\":\"$(date -u +%Y-%m-%dT%H:%M:%S.%3NZ)\"}" > yahoo-crumb-cache.json
  fi
else
  CRUMB=$(curl -s -b cookies.txt "https://query1.finance.yahoo.com/v1/test/getcrumb")
  echo "{\"crumb\":\"$CRUMB\",\"timestamp\":\"$(date -u +%Y-%m-%dT%H:%M:%S.%3NZ)\"}" > yahoo-crumb-cache.json
fi

# Step 3: Query screener API (this produces the exact JSON below)
curl -b cookies.txt -H "Content-Type: application/json" -d '{"size": 4, "offset": 0, "sortField": "intradaymarketcap", "sortType": "DESC", "quoteType": "EQUITY", "query": {"operator": "eq", "operands": ["exchange", "TOR"]}}' "https://query1.finance.yahoo.com/v1/finance/screener?crumb=$CRUMB"
```
